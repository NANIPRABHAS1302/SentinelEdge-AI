# SentinelEdge AI

Privacy-Preserving On-Device Intelligence for Snapdragon-Powered PCs

## Overview

SentinelEdge AI is a privacy-first desktop AI system designed to combine:

- Privacy-aware screen protection
- Person and face analysis
- Gaze and head-pose awareness
- Sensitive-content detection
- Hands-free computer interaction
- Local/on-device AI processing

## Project Status

Early development — repository and architecture setup phase.

## Planned Architecture

Webcam
? Vision Analysis
? Privacy Engine
? Sensitive Content Analysis
? Policy Decision
? Privacy / Accessibility Actions

## Development

The project is being developed with a hardware-agnostic inference layer so that the prototype can be developed on a conventional PC and later adapted for supported Snapdragon hardware.
